Mud Clarity
===========

Visualizes Riftshadow MUD area files: rooms, how they connect, and what is
wrong with them.

Requirements
------------
Windows 10 or newer with a graphics driver that supports Vulkan (current
NVIDIA, AMD and Intel drivers do). SDL3.dll is included; keep it next to
mudclarity.exe.

Running
-------
Double-click mudclarity.exe to open the window, or from a terminal:

    mudclarity.exe                    Open the window
    mudclarity.exe open area.lst      Open the window on a world
    mudclarity.exe area.lst           Check a world from the command line
    mudclarity.exe help               All the commands

In the window, press F1 for help and the keyboard shortcuts.
